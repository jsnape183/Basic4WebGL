# TileMap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `TileMap` BASIC class that loads a JSON 2D-array layer file and renders it as a grid of tiles from a uniform tileset image, with world-coordinate tile querying for collision detection.

**Architecture:** A new `_sbTilemaps` engine mixin (`tilemap.js`) handles all PIXI work — slicing the tileset, building a `PIXI.Container` of tile sprites, and querying by world position. A new `tilemap.bas` BASIC class wraps those engine calls via `call()`, following the exact same pattern as `animatedsprite.bas`. The container is returned as the raw `_handle` so `stage.add/remove` work without any changes to `stage.js`.

**Tech Stack:** TypeScript (tests), JavaScript (engine), softBASIC (class def), PixiJS 8, Vitest

## Task 2: BASIC class definition

**Files:**
- Create: `src/lib/Basic4WebGL/defs/tilemap.bas`
- Modify: `src/constants/packageModules.ts`

**Background on the `call()` parameter naming convention:** In softBASIC, a `call("...")` expression can reference a function's parameters using the pattern `lowercasefunctionname_paramname`. So a function named `load` with parameter `jsonPath` references it as `load_jsonPath`. For the constructor, the prefix is `constructor`.

- [ ] **Step 1: Create `tilemap.bas`**

```basic
Class
dim _handle

Constructor(tilesetPath, tileW, tileH)
    _handle = call("_sb.createTileMap(constructor_tilesetPath, constructor_tileW, constructor_tileH)")
    dim transform as ObjectTransform(call("this._handle"))
EndConstructor

function load(jsonPath)
    call("_sb.loadTileMap(this._handle, load_jsonPath)")
endfunction

function tileAt(x, y)
    return call("_sb.tileAt(this._handle, tileat_x, tileat_y)")
endfunction

function widthPx()
    return call("_sb.tileMapWidthPx(this._handle)")
endfunction

function heightPx()
    return call("_sb.tileMapHeightPx(this._handle)")
endfunction

EndClass
```

## Task 3: Engine implementation

**Files:**
- Create: `src/components/Runner/engine/tilemap.js`

**Background:** This file runs inside the game's sandboxed iframe alongside `pixi.js`. It has access to the global `PIXI` object and the `_sbAssets` mixin (defined in `assets.js`). `_sbAssets.get(name)` returns whatever `PIXI.Assets.load` resolved to — for image files that is a `PIXI.Texture`; for `.json` files PIXI automatically parses them and returns the plain JS object (the 2D array). No changes to `assets.js` are needed.

The `_handle` must be a raw PIXI `DisplayObject` (here, a `PIXI.Container`) because `stage.js` calls `app.stage.addChild(obj._handle)` directly. State (tile dimensions, frame array, loaded map data) is stored as underscore-prefixed properties directly on the container — the same pattern used in `animatedSprite.js`.

- [ ] **Step 1: Create `tilemap.js`**

```javascript
const _sbTilemaps = {
  createTileMap(tilesetPath, tileW, tileH) {
    tileW = Number(tileW);
    tileH = Number(tileH);
    const base = _sbAssets.get(tilesetPath);
    const cols = Math.floor(base.width / tileW);
    const rows = Math.floor(base.height / tileH);
    const frames = [];
    for (let r = 0; r < rows; r++) {
      for (let c = 0; c < cols; c++) {
        frames.push(
          new PIXI.Texture({
            source: base.source,
            frame: new PIXI.Rectangle(c * tileW, r * tileH, tileW, tileH),
          })
        );
      }
    }
    const container = new PIXI.Container();
    container._tileW = tileW;
    container._tileH = tileH;
    container._frames = frames;
    container._map = [];
    return container;
  },

  loadTileMap(handle, jsonPath) {
    const data = _sbAssets.get(jsonPath);
    handle.removeChildren();
    for (let row = 0; row < data.length; row++) {
      for (let col = 0; col < data[row].length; col++) {
        const id = data[row][col];
        if (!id) continue;
        const sprite = new PIXI.Sprite(handle._frames[id - 1]);
        sprite.x = col * handle._tileW;
        sprite.y = row * handle._tileH;
        handle.addChild(sprite);
      }
    }
    handle._map = data;
  },

  tileAt(handle, worldX, worldY) {
    const col = Math.floor((Number(worldX) - handle.x) / handle._tileW);
    const row = Math.floor((Number(worldY) - handle.y) / handle._tileH);
    if (row < 0 || row >= handle._map.length) return 0;
    if (col < 0 || col >= (handle._map[0]?.length ?? 0)) return 0;
    return handle._map[row][col] ?? 0;
  },

  tileMapWidthPx(handle) {
    return (handle._map[0]?.length ?? 0) * handle._tileW;
  },

  tileMapHeightPx(handle) {
    return handle._map.length * handle._tileH;
  },
};
```
